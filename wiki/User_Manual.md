# 📖 Wiki: Manual de Usuario — Precision Dot Tracking (DoTimer)

Domina tus rotaciones en **Turtle WoW** con la guía mágica de **DarckRovert**.

## 🚀 Paso 1: Configuración de Anclajes (Anchor Setup)
1.  Usa el comando `/dotimer` para mostrar los anclajes visuales.
2.  Mueve el anclaje de "Target Dots" a un lugar visible cerca de tu UnitFrame.
3.  Mueve el anclaje de "Buffs" a donde prefieras ver tus beneficios de clase.
4.  Vuelve a usar `/dotimer` para fijar la posición definitiva.

## 🎨 Paso 2: Filtrado de Hechizos
- ¿Demasiadas barras? En el panel de opciones de DoTimer, puedes elegir qué hechizos rastrear.
- **Whitelist**: Añade solo tus DoTs principales (ej: Corrupción, Maldición de Agonía).
- **Blacklist**: Ocluye hechizos de baja importancia para limpiar tu interfaz Diamond Tier.

## 🧠 Paso 3: Sincronización Visual
- Las barras de DoTimer v9.4.0 se integran visualmente con pfUI. Si cambias el tema de tu interfaz pfUI, los colores de DoTimer se adaptarán para mantener la coherencia del Séquito.

## 🛠️ Comandos Rápidos
- `/dotimer`: Bloquea/desbloquea los anclajes de las barras.
- `/dotimer reset`: Restablece la posición de fábrica de los temporizadores.
