# Security Policy — Precision Dot Tracking (DoTimer) 🔒🔮

Protegemos la integridad de tu información de combate en **Turtle WoW**.

## 🛡️ Soporte por Versión
| Versión | Estado |
| --- | --- |
| v9.4.x | ✅ Soportada |
| v9.3.x | ⚠️ Crítico |

## 🛡️ Reporte de Vulnerabilidades
Si descubres un bug que compromise la estabilidad del cliente de WoW durante el rastreo de múltiples objetivos o que cause caídas de FPS al cargar el diccionario de hechizos:

1.  **NO publique el exploit masivamente.**
2.  Reporta vía **Discord oficial** de **DarckRovert**.
3.  Incluye el log de `DoTimer -> SpellSystem/`.

## 🛡️ Protecciones Integradas
- **Memory Throttling**: El motor de rastreo purga automáticamente los registros de objetivos que han muerto o están fuera de alcance para liberar RAM.
- **Spell ID Validation**: Verificación de la legitimidad de las IDs de hechizos antes de iniciar un temporizador Diamond Tier.
